# Письмо во ВНИИПО: разъяснение п. 4.4.2 СП 1.13130.2020

Запрос во ФГБУ ВНИИПО МЧС России о порядке измерения ширины лестничных площадок и маршей при дверях, выходящих на лестничную клетку.

## Готовые файлы

| Файл | Назначение |
|------|------------|
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.docx` | Основной документ для отправки, Times New Roman, схемы в приложении |
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.pdf` | PDF-версия того же письма |
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.md` | Текстовая копия со схемами |
| `figures/` | Рисунки 1–6 в PNG и SVG |

Перед отправкой заполните исходящий номер, реквизиты организации, должность, Ф. И. О., телефон и адрес для ответа.

## Логика письма

Письмо построено так, чтобы ответ не свёлся к повторению текста нормы. Для типовой лестничной клетки (марш 1,20 м, площадка 1,40 м, полотно 0,90 м) на схемах показано, что при разных допущениях один и тот же объект даёт разные результаты замера, и по каждому расхождению задан отдельный вопрос:

| Вопрос | Схема | Разброс результата |
|--------|-------|--------------------|
| 1. Положение полотна: 90°, «до упора» или промежуточное | рис. 2 | 0,50 … 1,29 м |
| 2. Начальная точка на двери: полотно, ручка или доводчик | рис. 3 | 1,160 … 1,250 м |
| 3. Конечная точка: край марша, ограждение, препятствие, стена | рис. 4 | 0,90 … 2,40 м |
| 4. Какой размер площадки нормируется (A или L, связь с ГОСТ 9818) | рис. 1 | — |
| 5. Замер марша, если полотно заходит в его габарит | рис. 5 | 0,235 / 1,20 м |
| 6. Порядок проверки при нескольких дверях | рис. 6 | 0,25 … 1,15 м |
| 7. С какой требуемой величиной сравнивать результат | — | — |
