# Письмо во ВНИИПО: разъяснение п. 4.4.2 СП 1.13130.2020

Доработанный проект запроса во ФГБУ ВНИИПО МЧС России о методике измерения ширины лестничных площадок и маршей при дверях, выходящих на лестничную клетку.

## Готовые файлы для отправки

| Файл | Назначение |
|------|------------|
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.docx` | Основной документ Word со встроенными рисунками |
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.pdf` | PDF-версия для удобной отправки/печати |
| `Письмо_ВНИИПО_п_4_4_2_СП_1_13130_2020.md` | Текстовая копия со ссылками на схемы |
| `figures/` | Рисунки 1–6 (схемы точек замера) |

Перед отправкой заполните: исходящий номер, реквизиты организации-отправителя, должность, Ф.И.О., контакты и адрес для ответа.

## Что доработано относительно исходного черновика

1. Оформление как официального запроса во ФГБУ ВНИИПО МЧС России.
2. Ссылки на ранее данные разъяснения:
   - письмо ВНИИПО № 4772-13-4-4 от 10.08.2018 ([morozofkk.ru](https://morozofkk.ru/pisma-mchs/id2461/));
   - раздел Q&A на сайте ВНИИПО;
   - материалы с отсылкой к ГОСТ 9818 ([1-12.ru](https://1-12.ru/vopros/id219/)).
3. Конкретные вопросы по точкам замера (начало на двери, окончание на площадке/марше, угол открывания, сравнение с требуемой величиной, типовые планировки).
4. Шесть наглядных схем с перекрёстными ссылками в тексте письма.
